# Carpeta de BIOS (Opcional)

EmulatorJS cuenta con BIOS de simulación HLE de PlayStation 1 integrado, por lo que el juego puede arrancar sin BIOS externa.

Sin embargo, para máxima compatibilidad con Racing Lagoon (versión japonesa SLPS-02038 / SLPS-02039), puedes colocar aquí el BIOS oficial japonés:
- **`scph5500.bin`** (Japón)

O el BIOS estándar americano:
- **`scph5501.bin`** (NTSC-U)
