# Carpeta de ROMs para Racing Lagoon

Coloca aquí el archivo de tu juego. Los formatos soportados son:
- **`racing_lagoon.chd`** (Muy recomendado: comprimido sin pérdida, 1 solo archivo, ~250MB)
- **`racing_lagoon.pbp`**
- **`racing_lagoon.iso`**
- **`racing_lagoon.cue`** (junto con su archivo `racing_lagoon.bin`)

Si llamas a tu archivo `racing_lagoon.chd` o `racing_lagoon.bin`, el reproductor web lo detectará automáticamente.
También puedes arrastrar y soltar cualquier archivo ROM directamente en la ventana del navegador.
